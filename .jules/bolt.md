**[Performance Improvement in CSV Parser & Valid Parentheses]**
**Learning:** Replacing `.clone()` on strings inside a loop with `std::mem::take` provides zero-cost abstractions to prevent allocations. Avoiding `.clone()` in `csv.rs` parser helps a lot, as we don't want an extra allocation every field or every row. We also learned how important it is to pre-allocate capacity for dynamically growing collections like `Vec`.
**Action:** Use `std::mem::take(&mut field_buf)` instead of `field_buf.clone(); field_buf.clear();` when moving string data out of a temporary buffer. Always set capacity if the max bounds are known, like `Vec::with_capacity(s.len())` for stacking parentheses.
