💡 What
Implemented from-scratch Rust versions of foundational systems:
1. `HttpServer`: A minimal multithreaded HTTP/1.1 server.
2. `GitObject`: A content-addressable Git Object Store serializer and hasher.
3. `TarWriter`: A USTAR (Unix Standard TAR) archive builder.

🎯 Why
To build deep mastery of the stack by revealing how ubiquitous crates (`hyper`, `git2`, `tar`) work under the hood. These educational artifacts demonstrate string parsing over TCP streams, content-addressable hashing, byte-level block alignment, and strict documentation formatting with inline annotations.

📊 Impact
- Demystifies core infrastructure.
- Provides swappable trait-based designs (`Handler`) and generic structures (`TarWriter<W>`).
- Includes comprehensive tests, documentation, and specific notes on real-world constraints ("Tradeoffs", "Missing vs Production", "Benchmarking Notes").

🔬 Measurement
All new implementations include `#[cfg(test)]` modules with happy-path and boundary-condition coverage. Passed all existing tests and strict clippy linting under `-D warnings`.
